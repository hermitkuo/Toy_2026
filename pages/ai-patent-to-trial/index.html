四、十個關鍵方法

真正決定試驗品質的能力

1. Intended Use Decomposition

Population × User × Setting × Input × Output × Decision × Action × Benefit。

2. Estimand Framework

明確定義 strategy、population、outcome、intercurrent events、summary measure。

3. Decision Curve Analysis

判斷不同 threshold 下是否有 net benefit，而不是只看 AUROC。

4. Calibration Analysis

評估 calibration-in-the-large、slope、subgroup 與 temporal calibration。

5. AI Trial Sample Size

依診斷、prediction validation、cluster、superiority 或 non-inferiority 分別估算。

6. External Validation

優先 temporal、geographic、cross-institution；random split 不能代替外部驗證。

7. Human–AI Interaction

比較 AI alone、clinician alone、clinician + AI，並分析 error concordance。

8. Implementation Fidelity

測量 exposure、adoption、correct use、override、downtime 與 workaround。

9. Subgroup／Fairness

預先定義年齡、性別、疾病嚴重度、院區、資料來源等交互作用。

10. Post-deployment Monitoring

追蹤 data、concept、calibration、outcome、usage 與 safety drift。
