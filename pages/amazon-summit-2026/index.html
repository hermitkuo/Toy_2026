Keynote 主題演講

代理式 AI 全景 + OpenAI Codex + 客戶案例。定調全天，每人該去。

📋 課程介紹

AI 代理（AI Agent）的時代已經來臨。AWS 將揭示如何讓代理式 AI（Agentic AI）真正落地，從建構、部署到大規模擴展，為開發者移除障礙。將分享業界先驅的真實故事，瞭解領先企業如何運用 AI 與代理式架構實現突破性成果，並見證全新開發者工具與流程如何加速創新。

🎯 我想聽的課程綱要

  • 完整技術堆疊：build → deploy → scale 每一層對應哪些 AWS 服務（Bedrock AgentCore、Strands Agents SDK、Amazon Q、Kiro），彼此如何組裝。

  • 新工具清單 + 時程：這場宣布的新開發者工具/功能，哪些 GA、哪些預覽、何時可用。
  • 參考架構藍圖：一張可照抄的 agentic reference architecture（含 memory、tool、guardrail、observability 各元件）。
  • 落地失敗模式：領先企業踩過哪些坑、為何 PoC 卡住上不了 production。

分享製造業公司如何運用代理式編程工具搭配 Amazon Bedrock 上的 Claude 模型，從四個製造廠區的 ERP 匯出資料，快速完成第一個可用版本，並已在正式環境上線。探討非技術人員如何透過自然語言查詢料號資料、選擇 Amazon Bedrock 的原因、代理式編程互動風格，以及如何讓每位員工都能使用。
